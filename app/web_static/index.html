公网镜像（可选）

公网镜像配置教程

作用：把渲染好的配置推送到公网可读的镜像地址，外网客户端订阅该地址即可自动更新，NAS 本身无需任何公网条件。推送时机：产物内容变化后自动推送，内容无变化不重复推送。

凭证告知：配置文件内含全部节点凭证，推送到第三方平台即视为托管给该平台（镜像侧有 URL token 保护，但平台可见内容）。请知晓并接受后再启用。

方式一：Cloudflare Workers + KV（推荐，全程在自己电脑上操作，一次性）

思路：把 Worker（一小段公网读取程序）和 KV（云端键值存储）部署到 Cloudflare 免费版；NAS 把配置推上去，外网客户端订阅 Worker 的网址。

名字谁生成干什么用
url_token
（即 Worker 里的 MIRROR_TOKEN）		你自己随手生成的随机串藏在订阅网址里当门禁，没它一律 404
api_tokenCloudflare 网页上创建sub-hub 往 KV 写文件的钥匙；只存 NAS 本地，不进网址
  1. 准备：注册 Cloudflare（免费版每天 10 万次请求，个人足够）；电脑装 Node.js ≥ 18，然后 npm install -g wrangler、wrangler login（会弹浏览器，点 Allow）。
  2. 生成 url_token：PowerShell 执行
    -join ((1..32) | ForEach-Object { '{0:x}' -f (Get-Random -Max 16) })
    （或 Mac/Linux 用 openssl rand -hex 16），输出保存好 → 填入表单「url_token」。
  3. 创建 KV 存储：wrangler kv namespace create SUBHUB_MIRROR，输出里的 id → 填入「namespace_id」；同时把它填进仓库 deploy/cf-worker/wrangler.toml 的 id = 行（替换占位符）。
  4. 部署 Worker：
    cd deploy/cf-worker
wrangler secret put MIRROR_TOKEN   # 提示输入时，粘贴第 2 步的 url_token
wrangler deploy
    输出末尾的网址（形如 https://sub-hub-mirror.<你的子域>.workers.dev）→ 填入「worker_base」。
  5. 创建 api_token：Dashboard → 右上角头像 → My Profile → API Tokens → Create Token → 权限选 Account → Workers KV Storage → Edit，生成后 → 填入「api_token」；再到 Workers & Pages 页面右侧「Account details」复制 Account ID → 填入「account_id」。注意面板文字可能截断显示（带省略号），从浏览器地址栏 dash.cloudflare.com/<32位ID>/… 复制更稳妥。
  6. 回本页：提供方选「CF Workers + KV」，五个输入框按各自身旁标注的步骤号填好 → 勾选「启用」→ 点「保存并立即试推」。凭据只存 NAS 本地、页面不回显；以后留空输入框 = 保持原值。
  7. 验收：浏览器访问 https://<worker_base>/<url_token>/clash.yaml 能看到配置内容；把 token 改错应返回 404（与文件不存在表现一致，不泄露存在性）。把外网客户端订阅地址换成该 URL，之后产物变化会自动推送更新。

方式二：GitHub 公库随机路径

  1. 准备：一个 GitHub 公开仓库 + API Token（Fine-grained：仓库限定到该库，权限 Contents: Read and write）。
  2. 提供方选「GitHub 公库随机路径」，填「api_token / owner / repo」三个输入框（branch 留空默认 main）→ 勾选「启用」→「保存并立即试推」。首次推送自动生成 64 位随机路径并固定，订阅 URL 形如 https://raw.githubusercontent.com/<owner>/<repo>/<branch>/<随机路径>/clash.yaml。仅靠路径保密，请勿泄露完整 URL。
  3. 注意：客户端拉取 raw.githubusercontent.com 国内直连不稳定，建议客户端本身走代理拉取。

已保存凭据一律不回显（状态栏只显示「已配置」）。轮换 token、下线镜像等维护操作见仓库 deploy/cf-worker/README.md。
